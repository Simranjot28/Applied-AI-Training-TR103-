# Day 7 — API Fundamentals and OpenAI API

## 1. Objective

The objective of this session was to understand the fundamentals of Application Programming Interfaces (APIs) and explore how they enable communication between different software applications. The session introduced AI APIs, their role in integrating Large Language Models into applications, and the basic workflow involved in sending requests to an AI service and receiving generated responses.

## 2. Topics Covered

### Understanding APIs

An Application Programming Interface (API) is a mechanism that allows two software applications to communicate with each other through a defined set of rules. APIs make it possible for developers to use the functionality of an existing service without building every component from scratch.

For example, an application may use a weather API to retrieve current weather information or an AI API to generate answers to user questions. The application sends a request containing the required information, and the service returns a response that the application can process.

The basic API communication process includes:

- Preparing a request with the required information.
- Sending the request to the appropriate endpoint.
- Processing the request on the server.
- Receiving a response from the service.
- Using the returned data within the application.

### Introduction to AI APIs

AI APIs allow developers to integrate capabilities such as text generation, summarization, question answering, and other supported AI tasks into their applications.

Instead of running an entire language model locally, an application can send input to a model provided by an external service and receive its output through an API. The exact capabilities, request formats, and usage limits depend on the service being used.
